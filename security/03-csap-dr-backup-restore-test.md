# CSAP 재해복구(DR) 백업/복원 검증 테스트

## 1. 배경

### 가. 목적

1) CSAP 인증 유지·갱신 심사 요건 중 하나인 재해복구(DR) 검증을 위해, 연 1회 운영 서버와 DR 서버 간 백업 데이터 정합성을 전수 검증
2) [CSAP 유지보수 자동화](05-csap-maintenance-automation.md)의 연간 자동화 항목 중 실제 수행한 DR 검증 테스트를 별도로 상세화

## 2. 기대효과

### 가. 정량적 정합성 검증

1) DB·ElasticSearch 전 영역에 대해 운영-DR 간 데이터 정합성을 ROW COUNT/CHECKSUM/인덱스 사이즈로 정량 검증

### 나. 백업 저장소 자체의 무결성까지 검증

1) 단순 데이터 비교를 넘어, 공식 문서 근거로 백업 저장소(snapshot repository) 자체의 무결성까지 검증 절차에 포함해 테스트 신뢰도를 높임

### 다. AS-IS / TO-BE 비교

| 항목 | AS-IS | TO-BE |
|---|---|---|
| DR 검증 범위 | 자동화 스크립트 존재만 문서화 | 서비스별 DB(ERP/메일/그룹웨어인증/모바일/스팸필터/암호키관리) 전수 검증으로 구체화 |
| 검증 방식 | - | 운영-DR 간 전체 테이블 ROW COUNT + CHECKSUM 비교 |
| ElasticSearch 검증 | - | 인덱스 목록·문서 수·사이즈 비교 |
| 백업 무결성 | - | 공식 문서 기준 스냅샷 저장소 무결성 검증(`_verify_integrity`) 절차 반영 |

## 3. 구성도 (검증 흐름)

```
STEP 1  서비스별 DB(ERP/메일/그룹웨어인증/모바일/스팸필터/암호키관리) 대상 선정
  │
  ▼
STEP 2  운영-DR 서버 간 전체 테이블 ROW COUNT + CHECKSUM 비교
  │
  ▼
STEP 3  ElasticSearch 인덱스·문서 수·사이즈 비교
  │
  ▼
STEP 4  백업 저장소(snapshot repository) 무결성 검증 (공식 문서 근거)
  │
  ▼
STEP 5  전 항목 정상 확인 → CSAP 인증 심사 증적화
```

## 4. 성과

1) DB·ElasticSearch 전 영역에 대해 운영-DR 간 데이터 정합성을 정량적으로 검증하는 테스트 방법론을 확립
2) 단순 데이터 비교를 넘어, 공식 문서 근거로 백업 저장소 자체의 무결성까지 검증 절차에 포함해 테스트의 신뢰도를 높임
3) CSAP 인증 유지·갱신 심사에 필요한 DR 검증 증적을 매년 동일한 방법론으로 재생산 가능하도록 문서화
